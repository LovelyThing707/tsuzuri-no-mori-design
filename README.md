# 綴りの森 — デザイン第1稿

オンライン書店「綴りの森」の世界観と売り場の見せ方を確認するための、
ブラウザで触れるデザイン案です。スマートフォン（幅390px）を基準に作っています。

```
index.html
styles/   base.css（変数・タイポグラフィ） hero.css layout.css shelf.css（什器・本・影）
scripts/  main.js（視差と出現のみ）
assets/images/  書影
tools/    ページ生成と配信用ビルド
```

## 手元で見る

ES モジュールは使っていないため、ファイルを直接開いても表示できます。
書影は相対パスで読むため、サーバー経由のほうが確実です。

```sh
python -m http.server 5178
```

## 本の寸法

本の大きさは固定値ではなく、判型と背幅から算出しています。
各要素が `--h`（判型 mm）と `--t`（背幅 mm）を持ち、CSS 側で寸法に変換します。
Shopify に移す際は、この2つを商品のメタフィールドから出力すれば同じ見た目になります。

背表紙の幅は厚みに比例させていません。実寸のままだと薄い本が線のように潰れ、
指で触れる幅も確保できないためです。`--spine-base`（下駄）と `--spine-gain`（増分）で
差を圧縮しつつ、薄い順・厚い順の並びは保っています。

## 画面幅による違い

本を大きくするのではなく、見える冊数を増やします。
背表紙は一段あたり スマートフォン6冊／タブレット10冊／パソコン14冊。
森も同様で、広い画面ほど左右が広く見えます。

## ヒーローの森について

現在の森は CSS と SVG で組んだ仮のものです。
本番の画像に差し替えられるよう、この部分だけを入れ替えれば済む構造にしています。

## 配信

リポジトリには制作用のファイルも含むため、配信するものだけを `dist/` に集めています。

```sh
bash tools/build.sh
```

ページを組み直す場合：

```sh
python tools/gen_page.py
```
